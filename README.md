# 🌊 RS River Monitor

Painel público que acompanha, todos os dias, a vazão e o nível de 50 rios do
Rio Grande do Sul — cada estação comparada apenas ao seu próprio histórico.

**App:** https://river-monitor-guqdrxqwws7jogzwq9krcn.streamlit.app/

não é recomendação operacional.*
